Vistoria de Estoque — DTEL Telecom

Aplicativo web (HTML único, sem backend) para conferência de equipamentos e materiais em campo.

Funcionalidades
Cadastro do supervisor, técnico responsável e data/cidade da vistoria
Lançamento de produtos com busca/autocomplete, quantidade em sistema e quantidade física
Cálculo automático da divergência entre sistema e físico
Etapa de conferência antes da finalização
Assinatura digital (supervisor e técnico) direto na tela, via touch ou mouse
Geração de PDF da ficha de vistoria, pronto para impressão/envio
Funciona 100% no navegador — não depende de servidor ou banco de dados
Como usar

Basta abrir o index.html (ou acessar a versão publicada via GitHub Pages) em qualquer navegador atualizado, preencher as etapas do formulário e gerar o PDF ao final.
